# 獨旅與長天數旅行區段

2026-10-30，Asia/Manila。

行程設定的天數範圍由 1–60 調整為 1–365，支援 70 天旅行。輸入欄位及程式驗證使用相同上限；按新增區段或儲存時會重新讀取數字，避免手機鍵盤尚未送出 change 事件而漏存。

## 自訂區段

行程設定 → 旅行區段 → 新增區段。每段填「區段名稱」與「起始天數」，例如：

|名稱|起始天數|顯示範圍|
|---|---|---|
|城市探索|1|D1–D20|
|山海生活|21|D21–D45|
|地方觀察|46|D46–D70|

第一段須從第 1 天開始，起始天數不能重複或超出旅程，名稱不能空白。系統依起始天數排序，結束日接到下一段前一天；最後一段延伸到旅程最後一天。增加旅程天數時，最後一段會延長；縮短後若有區段起點超出範圍，需先調整區段才能儲存。

主畫面的「旅行區段」選單只顯示所選段的日期；日期列保持單行橫向滑動。設定頁的每日主題與花費的每日明細依區段收合，展開後有捲動範圍，不一次展開 70 天。各天原本的主題與地區仍可個別設定。

刪除區段只合併顯示範圍，不刪除行程、筆記或每日主題。取消設定不儲存草稿。舊旅程沒有區段時，先顯示「整趟旅行」；開啟設定後可自行分段，無須搬移記錄。整份 PDF／JSON 匯出仍保留完整旅程。

## 獨旅設定

設定頁已移除旅伴與分組欄位，新旅程預設只有「我」。舊內容檔的 people、groups、owner 及既有分攤資料保持相容，這次不自動刪除或重新分配既有金額。

## 移動日、個人記帳與全頁區段（討論確認後實作）

每日地點採路線標題：`克拉克 → 碧瑤 · 移動日`，住宿另列。每日可新增、移除、往前調整多個地點；舊 `region` 讀為單一地點，新資料另存 `locations` 順序與 `overnight`，保留第一地點的 `region` 供舊版讀取。主題不受移動路線影響。

個人花費延用原本備份已涵蓋的 `misc` 文件，新增 `kind: expense | exchange`。花費支援 USD／PHP／TWD、現金／刷卡及最多兩位小數；既有 JPY 記錄仍可讀寫。新紀錄以完整 ISO 日期定位，跨年亦能歸入正確旅行天數；舊 `day: M/D` 仍可讀取。換匯記錄實付 `amt/cur` 與實收 `toAmt/toCur`，以實收÷實付計算成交匯率，同幣、零或無效換匯不可儲存。手續費另記支出。

總計保留各原幣，另用 `config.estimateRates.USD/PHP` 手動匯率估算台幣。未填匯率明示未換算，不把不完整估算標成全部總額。選填 `actualTwd` 會取代該筆估算；換匯不加入原幣或台幣支出。行程卡金額另置「行程預算」，不與實際花費重複計入。既有分攤資料只在有歷史記錄時出現，沒有自動刪除、轉幣或分配。

每日路線設定、花費與換匯明細、每日實際花費總計、日期筆記、既有分攤與行程預算類別細項都依相同區段收合；主行程只顯示所選區段的日期。日期選單依區段分組，旅程外或整趟記錄另保留。PDF 為靜態文件，路線與住宿可列印，實際支出另列，不能互動折疊。備份仍為 `trip-content` v1，路線與匯率隨 config、花費與換匯隨 misc 匯出；沒有新增帳號或雲端連線。
